
# Python Exception Handling

## Introduction
Exception handling helps a program handle runtime errors without stopping unexpectedly.

## Keywords
- try: Contains code that might raise an exception.
- except: Handles a specified exception.
- finally: Executes whether an exception occurs or not.

## Common Errors
1. ValueError: Occurs when a value has an inappropriate type or format for an operation.
2. ZeroDivisionError: Occurs when dividing a number by zero.
3. IndexError: Occurs when accessing a list position that does not exist.
4. KeyError: Occurs when accessing a missing dictionary key.

## Benefits
- Prevents unexpected program termination.
- Provides meaningful error messages.
- Improves program reliability and user experience.

## Conclusion
Exception handling allows Python programs to fail gracefully and handle errors appropriately.
