
# Python Exception Handling

## Overview
This project demonstrates how to handle runtime errors in Python using try-except-finally blocks.

## Programs
- `src/try_except.py`: Handles invalid input and division by zero.
- `src/common_errors.py`: Demonstrates handling ValueError, ZeroDivisionError, IndexError, and KeyError.

## Documentation
See `docs/exception_handling_notes.md` for explanations of exception handling and common errors.

## Screenshots
The `screenshots/` folder contains screenshots of successful program execution and handled errors.

## Concepts Learned
- try-except blocks
- Handling common runtime errors
- finally blocks
- Writing programs that fail gracefully
